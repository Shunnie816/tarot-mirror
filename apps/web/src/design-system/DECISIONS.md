# 判断の記録 — リーディング表示画面（第1ラウンド）

`claude design` の出力をそのまま残したもの。トークンの値を変えるときはここも併せて更新すること。

## 行長（measure）

`--measure-reading: clamp(18rem, 92vw, 38em)`

- 上限を `38em` にした。`em` は本文サイズ基準なので、日本語では**全角およそ38字**にあたる（全角35〜45字の範囲の下寄り）。
- 下寄りにした理由は行送りが `2` と広いこと。行送りが広いほど視線の戻り先を見失いにくいので短め〜中程度の行長が快適で、`45字`だと1440px幅でも1行が長く感じる。
- 幅の単位を `px` ではなく `em` にしたのは、将来本文サイズを上げたときに行長が自動追従するため（文字数基準を維持できる）。`em` は使用箇所の font-size で解決されるので、`max-width` をあてる読み物カラムに `font-size: var(--text-body)` を併記している（16px 基準で解決すると約32字になり短すぎる）。
- 下限 `18rem`（288px）は 320px 端末での最小読み幅。中間の `92vw` はモバイルで左右に必ず余白が残る値。
- ウィンドウ幅は本文幅に一切関与しない。ページは1カラムのまま、`max-width: var(--measure-reading)` を中央寄せするだけ。これで PC→モバイルは組み直しなしで通る。

## 段階開示の操作

- **1ポジションずつ、明示的なボタンで開く。**「これまで」は最初から開いており、その下に「「いま」をひらく」→「「この先」をひらく」→「三枚をとおして読む」の順で、そのときの次の一手だけが出る（同時に2つ以上のボタンは出ない）。
- ボタンのラベルは**次に読むものの名前**（"続きを読む" ではない）。何が開くか分かった上で自分の意志で開く動作にしたいので、汎用ラベルを避けた。
- アコーディオン（開閉トグル）にしなかった理由：閉じられると「読み返す」動作が操作になる。読み終えたものは残す。
- スロット的な連打を誘発しないよう、ボタンは幅いっぱい・`min-height: 56px`・枠線のみ。ホバー限定の操作はゼロ（ホバーは背景がわずかに持ち上がるだけ）。
- 開いたブロックは 520ms / ease-out で下から10pxのフェード。`prefers-reduced-motion` では 1ms のフェードのみ。
- 「三枚をとおして読む」で〈全体をとおして〉〈考えてみるための問い〉〈締めの一文〉がまとまって出る。ここは横断的な観察なので、三枚を読み終えるまでは存在させない。

> 第2ラウンドで**開示の単位は「1枚」から「群」に変わった**。理由は `DECISIONS-round2.md` を参照。

## 明朝／ゴシックの境界

境界は「**読むもの／位置を示すもの**」で引いた。

- **明朝（`--font-reading`）** = 利用者が言葉として読むもの：解釈本文、全体をとおしての本文、振り返りの問い、締めの一文、カード名、スプレッド名（画面タイトル）、そして利用者自身の問い。
- **ゴシック（`--font-ui`）** = 読み物ではなく構造を指し示すもの：ポジション名（これまで／いま／この先）、正位置・逆位置、セクション見出し、ボタン、"あなたの問い" などのラベル。
- 判断が分かれた2点：
  - **カード名は明朝。** 象徴の名前であり読むもの。ラベル側に置くとカテゴリ名（＝答えの分類）に見える。
  - **セクション見出しはゴシック。** 「全体をとおして」はエンジンの見出しでアプリの言葉。本文と同じ明朝にすると本文の一部に読めてしまう。
  - **利用者の問いは明朝**（本文より細い weight 300 + 「」で引用扱い）。アプリの言葉ではなく利用者の言葉なので、ゴシックのラベル体系に入れない。

## その他

- カードは文字のみ。画像枠は作らない。正逆は極小ゴシックの枠つきラベルで、カード名とベースライン揃え。
- 固定高さは一切なし。すべて flex + `gap`。本文が1.5〜2倍になっても余白のリズムだけが伸びる。
- スコア・ゲージ・星・パーセンテージ・バッジは不使用。LLM整形版が入っても同じ型のまま流し込む（差別化する装飾を持たない）。
- 色は彩度上限 0.072（テラコッタ）。藍は 0.052。地は 0.009。
